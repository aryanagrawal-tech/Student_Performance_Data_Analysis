# Student Performance & Academic Factors Analysis

## 📌 Project Overview

This project analyzes student academic performance using Python, NumPy, Pandas, Matplotlib, and Seaborn.

The main objective is to explore:

> What factors are associated with student academic performance?

The analysis focuses on study hours, attendance, assignments, midterm scores, sleep hours, internet access, extracurricular activities, and final scores.

---

## 🎯 Objectives

- Generate and work with a student performance dataset
- Inspect and understand the dataset
- Identify missing and invalid data
- Clean the dataset
- Perform exploratory data analysis
- Calculate statistical measures
- Analyze correlations between variables
- Visualize the relationship between study hours and final score
- Identify performance patterns
- Document the findings
